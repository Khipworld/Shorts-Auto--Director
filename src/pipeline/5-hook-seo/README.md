# [5] 플랫폼별 후킹·SEO 분석

유튜브 쇼츠/틱톡/릴스 등 플랫폼별 후킹 문구, 해시태그, 권장 길이·자막 스타일 제안.

**상태**: 구현 완료 — [generateHookSeo.server.ts](./generateHookSeo.server.ts)

- [platformSpecs.ts](./platformSpecs.ts) — 플랫폼별 권장 길이/화면비/자막 스타일 (일반 실무 가이드, 배포 전 최신 정책 재확인 필요)
- [3]검증 결과에서 `unverified` 항목은 제외하고 후킹 문구를 생성 — 검증 안 된 사실로 홍보 문구를 만들지 않음
- 플랫폼마다 다른 후킹 문구 3개 + 해시태그 + 썸네일 문구를 한 번에 생성 (요구서: "동일 주제라도 플랫폼마다 다른 버전 제공")

**주의**: [[feedback-shorts-hook-editing]] — 이 문구 생성 자체는 화면 전환 속도와 무관하지만, 실제 영상 편집 단계에서 카드 전환 속도를 더 빠르게 하는 방향은 이미 거절된 적 있음(정부지원사업 쇼츠 시리즈 기준). 후킹 개선은 전환 타이밍이 아닌 문구/노출 순서로 접근할 것.

**엔드포인트**: `POST /api/pipeline/5/hook-seo { groupId, platforms?: string[] }` (미지정 시 3개 플랫폼 전부)
